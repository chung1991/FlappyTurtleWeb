# Flappy Turtle Web

Flappy Turtle as a web game. Flap the turtle through the pipes and try to beat your best score. Built with HTML5 and WebGL, with no libraries or build step.

## How to run

Serve this folder over HTTP:

```bash
python3 -m http.server 8765 --directory FlappyTurtleWeb
```

Then open <http://127.0.0.1:8765/> in a browser.

## How to play

- Click, tap, or press Space / ↑ / W to flap.
- P or Esc to pause and resume.
- Enter to play from the title screen, or replay after game over.
- R to replay, M to mute.
